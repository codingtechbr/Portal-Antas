# Portal Antas Bahia

Site de notícias de Antas-BA e região, em parceria com o [Achei Fácil](https://achei-facil.vercel.app/).

- Site estático (HTML, CSS e JavaScript) — publicado na Vercel.
- As notícias ficam no Firebase (coleção `noticias`) e são publicadas pelo painel `admin.html`.
- Rádio ao vivo: Rádio Tropical 87.9 FM (Antas).
